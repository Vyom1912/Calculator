# 🧮 Calculator

A clean, simple calculator for everyday arithmetic.

## ✨ Features

- Addition, subtraction, multiplication, division and percentage
- **AC** to clear everything and **DEL** to delete the last character
- `00` and decimal point buttons
- Displays the running expression and the result

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
